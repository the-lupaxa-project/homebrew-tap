    ### Formulae

    A formula file points at a tagged release of a tool repository and names that tool's licence. The licence file in the tool's repository is the one that applies to the code you install. Read that file before you copy the tool. A tool's
    licence does not licence this website, and this website does not replace the licence of the tool.
